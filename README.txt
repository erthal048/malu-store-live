MALU STORE LIVE — DEPLOY RENDER

Arquivos para subir na raiz de um repositório GitHub:
- server.py
- requirements.txt
- index.html
- render.yaml

No Render, crie um Web Service a partir do GitHub.
Build Command: pip install -r requirements.txt
Start Command: python server.py
Plan: Free
Variáveis:
VERIFY_TOKEN = MALU_LIVE_VERIFICAR_2026
APP_SECRET = (App Secret do seu app Meta; não compartilhe)

Depois do deploy, a URL do webhook será:
https://SEU-SERVICO.onrender.com/webhook
